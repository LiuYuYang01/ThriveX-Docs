# 第三方配置

入口：**系统 > 第三方配置**。

第三方配置用于接入对象存储、邮件、百度统计、高德地图、人机验证等服务。

> Key、Token、Secret 这类信息不要公开，也不要提交到仓库。

## 对象存储

用于保存图片和附件。

| 字段 | 填写说明 |
| --- | --- |
| Access Key | 存储平台的访问 Key |
| Secret Key | 存储平台的私密 Key |
| 访问域名 | 文件访问域名，如 `https://img.example.com` |
| 存储桶 | Bucket 名称 |
| 地域 | Endpoint，如 `s3.cn-east-1.qiniucs.com` |
| 根目录 | 文件目录，建议 `static` |

七牛云详细配置看：[对象存储](../../项目部署/API/对象存储)。

## 邮件提醒

用于评论、留言等通知。

| 字段 | 填写说明 |
| --- | --- |
| SMTP 主机 | 如 `smtp.qq.com` |
| 端口号 | 常用 `465` 或 `587` |
| 发件邮箱账号 | 用来发邮件的邮箱 |
| 授权码 / 密码 | 邮箱后台生成的授权码 |

发不出去时检查 SMTP 是否开启、授权码是否正确、服务器端口是否放行。

## 百度统计

用于查看访问数据。

| 字段 | 填写说明 |
| --- | --- |
| 站点 ID | 百度统计里的 siteId |
| Access Token | 百度统计接口 Token |

## 高德地图

用于足迹地址解析和地图展示。Key 需要开通 Web 服务 API。

解析失败时检查 Key 是否正确、限制域名/IP 是否包含当前服务器。

## 人机验证

用于减少垃圾评论和留言。配置后建议到前台评论区测试一次。
